### What I work on

I'm a **Manager at Deloitte** focused on the intersection of **AI Engineering** and **Cybersecurity** — helping organizations adopt AI responsibly while keeping their security posture strong. My work spans building agentic AI systems, designing secure cloud architectures, and embedding security into every stage of the AI/ML lifecycle.

I'm particularly interested in:
- 🤖 **Agentic AI** — multi-agent systems, RAG pipelines, and LLM orchestration at production scale
- 🔐 **AI Security** — prompt injection defense, LLM guardrails, secure AI gateway patterns
- 🛡️ **Enterprise Cybersecurity** — zero trust architecture, ISPM, DevSecOps, compliance-as-code
- ☁️ **Cloud Security** — Azure and AWS security posture management, infrastructure-as-code security
